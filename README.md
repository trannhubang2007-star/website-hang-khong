# Aviation Student Website

Website tĩnh HTML5 + CSS3 phục vụ bài tập xây dựng website.

## Cấu trúc
- index.html: Trang chủ
- about.html: Giới thiệu
- study.html: Học tập
- contact.html: Liên hệ
- css/style.css: Giao diện dùng chung
- images/: thư mục dành cho hình ảnh

## Chạy trên máy
Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong VS Code.

## GitHub Pages
1. Tạo repository trên GitHub.
2. Upload toàn bộ file/thư mục.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → branch `main` → `/ (root)`.
5. Lưu và chờ GitHub Pages triển khai.

## Nguồn
Biểu tượng sử dụng emoji nên không cần tải tài nguyên hình ảnh bên ngoài.
